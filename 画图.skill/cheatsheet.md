# 速查卡（画图.skill）

## 一步构造卡（目标 → 操作）

| 想要 | 操作 |
|---|---|
| 中点 | Ctrl+M 或 点工具组→中点（选两点/线段） |
| 交点 | Ctrl+Shift+I 或 点工具组→交点 |
| 垂线 | 线线关系→垂线（点+线） |
| 角平分线 | 线线关系→角平分线（选 A,B,C，顶点在中间） |
| 切线 | 线线关系→切线（点+圆）；公切线=两圆 |
| 指定半径圆 | 圆与弧→指定半径圆（圆心，输半径可变量） |
| 椭圆（按定义） | 圆锥曲线→第一定义（两焦点+一点），设定里切类型 |
| 抛物线（焦点准线） | 圆锥曲线→第二定义（点+线），e=1 |
| 正多边形 | 多边形工具组→正多边形（定边数可选） |
| 函数曲线 | 函数图象→y=f(x)；参数式用 t |
| 动点沿曲线走 | 变量 t + 直角坐标点(x(t),y(t)) + 动画驱动 t |
| 批量曲线族 | 轨迹：驱动元素（含变量）→最后选目标元素 |
| 重复结构（雪花） | 迭代：原象+映象规则+深度 N |
| 平移/旋转/缩放 | 变换组：先选源对象，再定基准（标记的默认用） |
| 测量距离 | 选两点→计算|测量 |
| 2D 切坐标系 | 快捷工具栏→坐标系；自定义坐标系可调比例 |
| 3D 旋转体 | 旋转面：母线+轴线；转角关联变量可动画 |
| 3D 切割动画 | 切割：实体+多个平面，自动出动画按钮 |
| 3D 相贯线 | 线工具组→相贯线（两曲面/面） |
| 3D 球缺/球扇 | 球属性→缺口（按纬度挖） |
| 台变锥/柱 | 圆台/棱台属性→锥度（0=锥，1=柱） |

## 快捷键（常用）

Esc 回选择态 · Ctrl+Z/R 撤销重做 · Ctrl+C/V 复制粘贴 · Del 删除 · Ctrl+E 编辑定义 · Ctrl+P 属性 · Ctrl+H 隐藏 / Ctrl+Shift+H 全显 · Ctrl+K 显标签 · Alt+↑/↓ 父/子元素 · Ctrl+方向键 微调 · Alt+= 计算 · Ctrl+Shift+P 新建参数 · 空格 重复上次构造/变换 · P 预览 · Q 还原场景(3D) · Z/X/Y 三视点(3D) · ! 强制更新

## 函数速查（表达式可用）

- 算术：abs, square, cube, sqrt, cbrt, gcd, mod, round, pow, exp, log, log10, fix, floor, ceil, vpa
- 逻辑：and, or, not, sign, less, lesse, if(条件,值1,值2), prime, parity
- 三角：sin, cos, tan, cot, sec, csc, asin, acos, atan, sinh, cosh, tanh
- 统计：random, randomInt, factorial, max, min
- 常量：pi, e

## 动画调参

- 时长 = 步数 × 间隔；要平滑→步数↑；要快→间隔↓。
- 多变量动画：序列设并行/串行，类型往返/重复控循环。

## 测量对照（当前坐标系下）

2 点→距离 · 3 点→角+比例 · 2 线段→长度比 · 点+线段→点值/投影点值 · 点+圆/弧→点值 · 路径→长度 · 3D 实体→体积/面积 · 3D 直线→方程/向量分量 · 3D 向量→坐标分量/模长/夹角

## 智能画笔提示词卡

垂直→垂足 · 平行→线上点 · 相等→等分点 · 平行且相等→平移平行四边形 · 中点→MidPoint · 垂直相等→中垂线+定长圆 · 过点交于线→ParallelIntersection · 切线→TangentLine（等价泰勒斯构造：以 OP 为直径作圆 ∩ 原圆）· 平行/垂直相交→交点 · 定长→圆 · 定比→缩放

## 五心公式卡

重心 G=(A+B+C)/3 · 内心 I=(aA+bB+cC)/(a+b+c) · 外心 O=解 2×2 方程组(等距) · 垂心 H=A+B+C−2O · 欧拉线：O-G-H 共线且 HG=2GO · 欧拉公式 d²=R²−2Rr

## 指令作图卡（AI 出图）

三要素：画什么 + 哪些可变 + 怎么看得清。红线：一拖一对（拖参数核对数学事实；判定反相关立即停用）。不满意→改提示词重来，不手改。验收三档 12 项（入口/真机/教学可用），详见 chapters/指令作图与人工验收.md。
