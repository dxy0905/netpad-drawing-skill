# 2D 函数图象 · 变量 · 动画

> 手册来源：2D §4.8、§4.9；函数库 §12

## 函数图象工具组（§4.8）

| 类型 | 用法 |
|---|---|
| 自定义坐标系 | 建自定义坐标系（比例可调），函数画在**当前坐标系**下 |
| y=f(x) | 直接输入表达式，如 sin(x)、x^2+2x+1 |
| x=g(y) | 横纵互换的函数 |
| 参数方程 | x(t)、y(t)，配合变量 t 使用 |
| 极坐标方程 | ρ(θ) |
| 隐函数方程 | f(x,y)=0（曲线/区域） |

- 表达式中可用变量、常量（pi、e）和全部内置函数（见 cheatsheet.md 函数速查）。
- 参数方程+滑杆 t 是"动点沿曲线运动"的标准做法。

## 变量（§4.9.1）

- 变量对话框：变量名 + 变化范围 + 增量；一次可"+"定义多个。
- 生成**滑杆**：可播放（按增量连续变化）、可拖动、可点数字直接输入当前值。
- 滑杆属性：可隐藏播放按钮/滑杆/变量名、设显示精度、播放方向。
- 变量是全局可引用的"数"，坐标、半径、角度、文本都能引用。

## 动画（§4.9.2）

- **动画=驱动变量**：对话框填变量名、起止值、步数、间隔时间 → 生成动画按钮。
- 时长公式：`步数 × 间隔 = 一次动画时长`。步数↑平滑，间隔↓快速。
- 多变量：可"+"添加多个，序列设**并行/串行**；类型（往返/重复）与次数控制循环。
- 并行动画时长不同：先完成的等后完成的，再一起继续。
- 按钮支持正放/倒放/暂停/继续/停止。

## 计算|测量（§4.9.6）

- 计算：不选中任何对象→计算对话框→输入表达式→画布显示（6 种展示类型：变量名+计算式/值/名称+值/计算式/名称+计算式/变量名+名称+计算式）。
- 测量对照表（在**当前坐标系**下）：

| 选中 | 测量结果 |
|---|---|
| 1 个点/线/圆/弧/多边形/圆锥曲线 | 对应几何量（半径/面积/周长/方程…） |
| 2 点 | 距离 |
| 3 点 | 角、比例（13 距:12 距） |
| 标注角 | 角度（按度） |
| 点+线段 | 点在线段上的点值（不在线上=投影点值） |
| 2 线段 | 长度比 |
| 点+线型元素 | 点值（不在其上=最近点点值） |
| 1 路径/曲线 | 长度 |

## 图片 · 音频 · 自定义函数（§4.9.4/5/8）

- 图片：上传/粘贴图片，可附着到点上（随点动）、可裁剪。
- 音频：录制并上传，做发音/讲解按钮。
- 自定义函数：命名 + 表达式，之后计算表达式里可调用。
