# 2D 绘图与构造

> 手册来源：2D 手册 §3 绘图工具栏、§4.1-4.6、§4.10

## 绘图工具栏 12 工具（"先工具后选择"）

| # | 工具 | 用途 |
|---|---|---|
| 1 | 选择\|拖动 | 点选（悬停变手型）/框选（拖红区域）/轮选重叠对象（反复单击逐层下移） |
| 2 | 点 | 空白处=自由点；对象上=半自由点（父对象高亮虚线） |
| 3-5 | 线段/直线/射线 | 两点生成 |
| 6 | 多边形 | PC 依次点顶点，末点双击闭合 |
| 7 | 圆 | 自由绘制；或过已有点/线 |
| 8 | 绘图\|标注 | 画笔手绘；标注线（选线型元素）、标注角（选 A,B,C 标 ∠ABC） |
| 9 | 文本\|命名 | 文本可插入：动态变量、条件文本、公式；给元素命名（有自动命名规则） |
| 10 | 智能画笔 | 智能感应：相等线段/垂直/平行/中点/过点交线/切点切线/平行相交/垂直相交/相切 |
| 11 | 批注 | 手写演示，不保存 |
| 12 | 停靠 | 工具栏上/下移，适配一体机 |

- 选择态关键操作：Esc 退出绘图态回选择态；Alt+↑ 选父元素、Alt+↓ 选子元素。
- 文本里插动态变量：文本编辑框内引用变量/点值，随参数实时刷新。

## 点工具组（§4.1）

| 工具 | 用法 |
|---|---|
| 中点\|中心 | 两点中点 / 线段中点 / 多边形等中心 |
| 交点 | 选中两对象构造交点 |
| 圆锥曲线焦点/顶点 | 从圆锥曲线提取焦点/顶点 |
| 直角坐标点 | 输 (x,y)，可为表达式：定值=定点，含变量=半自由点 |
| 极坐标点 | 输 (ρ,θ) |
| 元素上的点 | 线型元素上的半自由点（带点值）；复合路径上的点 |
| 元素内的点 | 圆内/多边形内的点（点值由位置定义） |
| 最近点 | 点到对象的最近点 |
| 附着\|分离 | 附着：点吸附到对象；分离：解除；合并：点合并到点 |

## 线工具组与线线关系（§4.2-4.3）

- 线段/直线/射线：两点；过点的直线：一个点。
- 垂线：点+线；平行线：点+线；中垂线：两点或一线段；角平分线：三点（角顶点在中间）或两线。
- 切线\|公切线：点+圆=切线；两圆=公切线。
- 渐近线/准线：作用于圆锥曲线。
- **轨迹**：选含变量的驱动元素 + 最后选目标元素；或直接选含驱动变量的目标元素。轨迹是把"拖动的过程"固化成曲线，是批量构造的核心手段。

## 多边形与圆弧（§4.4-4.5）

- 多边形：依次选点；凸包；正多边形（定边数可选）；路径（多元素连成连续通路，其上可放半自由点）；多边形的交；直纹面。
- 圆：两点圆（圆心+半径点）、指定半径圆（可变量/表达式）、点线圆（圆心+定长线段）、过三点圆。
- 弧（三种三点弧，属性→设定可互切）：过三点的弧（A→B→C 顺序）、圆周角上的弧（∠ABC 所对弧）、圆心与两点的弧（A 圆心、B 起点、C 控制终点，逆时针）。
- 已知圆上的弧：圆+圆上两点，从第一点逆时针到第二点。

## 圆锥曲线（§4.6）

- **第一定义**：三点=两焦点+曲线上一点；属性设定可切椭圆/双曲线/抛物线（抛物线以第三点为焦点、前两点连线为准线）。
- **第二定义**：焦点+准线，离心率 e：e>1 双曲线、e=1 抛物线、0<e<1 椭圆、e=0 一点。点在线上报"构造条件不足"。
- 过三点抛物线：三点，设定里"垂直"切换对称轴方向；三点共线则无法构造。
- 过五点圆锥曲线：5 点确定一般二次曲线（3 点共线则失败）。
- 标准椭圆/标准双曲线：一个中心点，对话框填 a/b/c/e 中任意 2 个；椭圆 a=b 时退化为圆。**在当前坐标系下绘制**。

## 向量（§4.10）

- 向量：两点=以先选点为起点；单点=原点→该点；点+向量=平移副本。
- 加法：起点相同时和=平行四边形对角线；和向量起点=第一个向量起点。
- 减法：起点相同时差向量=第二向量终点→第一向量终点；否则起点=第二向量起点。
- 数乘/点积/叉积：叉积在平面是标量（3D 才是向量，见 3D 篇）。
