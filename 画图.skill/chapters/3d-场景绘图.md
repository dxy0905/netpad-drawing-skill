# 3D 场景与绘图

> 手册来源：3D §1-3

## 编辑器与场景

- 入口：netpad.net.cn/svg.html → 右上角 3D 图标；画布固定 1366×768，可缩放（缩放中心=光标）。
- 场景=右手系三维坐标系（与我国教材一致），**3D 不支持多坐标系**；xoy/xoz/yoz 平面默认不显示。
- 场景操作：左键拖空白=旋转视角（水平拖绕 Z 轴、竖直拖绕过原点的水平线）；滚轮=缩放（改景深）；拖坐标系原点=整体移动。
- 画布操作：右键拖=移动画布；触控板双指=缩放画布；双击在"操作场景/操作画布"间切换；【还原画布】【还原场景】(Q 键) 复位。
- 视点快捷键：Z=xoy 顶视、X=yoz、Y=xoz；快捷工具栏可切换"显示 xoy/yoz/xoz 平面"。

## 3D 绘图工具（§3）

| 工具 | 要点 |
|---|---|
| 选择\|拖动 | 光标悬停显示类型名后点选；选中粉色包围；重叠对象优先选小的（点>线>面）；**不支持框选** |
| 点 | 画点带 1-3 条虚线坐标参考线；Esc/右键结束；自由点红色，半自由点黄色；自由点 XYZ 只能数值不能变量 |
| 线段 | 两点；直线/射线通过属性"设定/线形"切换；线宽最大 2 |
| 圆 | **点法圆**：第一点圆心、第二点与第一点连线=法线；半径默认 4，可设变量 |
| 文本\|命名 / 批注 / 停靠 | 同 2D |

- 拖动对象：若父对象是自由点/约束点，拖子对象会连带拖父对象。
- 对象列表、导航栏用法与 2D 一致（主题为 3D 主题）。

## 3D 点工具组（§4.1）

- 中点|中心：中点或几何体中心；直角坐标点（x,y,z）；元素上的点（含复合路径）；最近点；交点。
- 多面体顶点：从多面体提取顶点。
