## 重点案例：第1篇 化曲为直短程线（蚂蚁爬行最短路径）

1. **题目**：蚂蚁从圆柱侧面 A 处沿侧面爬到对角 B 处捕食，用网络画板 3D 制作最短路径（底面半径 r、高 h 可控）
2. **参数**：新增变量 h 控制圆柱高（0.5~10，增量 0.01）；新增变量 k 控制展开进度（0~2π，增量 0.01）
3. **展开圆柱侧面**：用**函数曲面**工具制作侧面展开过程，曲面参数方程：
   - x = if(u<k, u*r, k*r + r*sin(u-k))
   - y = if(u<k, 0, r - r*cos(u-k))
   - 定义域：0≤u≤2π，0≤u≤h（u 同字符复用，含义为两个方向参数）
   - 思路：u<k 时侧面未展开（保持弧长 u·r），u≥k 时已展开为平面（sin/cos 折叠）
4. **最短路径**：展开图上 A→B 为直线（化曲为直），沿直线卷回圆柱即最短路径
5. **动态**：拖动 k → 圆柱侧面逐步展开/卷回，直线路径在 3D/展开态间切换

## 重点案例：第7篇 谢氏四面体（二重迭代）

1. 谢尔宾斯基四面体 = 四面体细分分形：每个四面体取四角小四面体 + 中心空隙
2. 实现：**二重迭代**（两次迭代嵌套：第一次分割，第二次在各子体上重复）
3. 难点：二重迭代参数与深度控制，避免迭代爆炸（性能优化）

## 教学要点

- 3D 制作的通用套路：**参数变量（控制量）→ 函数曲面/体构造 → 迭代细化 → 投影/旋转观察 → 颜色区分**
- if 条件分段是 3D 动态展开（圆柱展开/纸板折叠）的核心表达式技巧
- 分形（谢氏四面体）、球面网格（十二面体）都靠迭代：深度小（如 5）保证流畅
