## 点值（§10）— 数形结合的枢纽

半自由点在路径上的每个位置对应一个"点值"。路径可为直线/射线/线段/封闭折线/圆/圆弧/轨迹/函数图象。

| 路径 | 默认点值定义 |
|---|---|
| 线段 | 0~1，起点到点的距离/线段长 |
| 直线（两点构造） | 0~1 在两点间；向终点外 >1；向起点外为负；=起点到点距/两点距（同向正、反向负） |
| 直线（线+点构造，如垂线） | 沿用父直线的点值规则（父两点距离为单位 1） |
| 直线（两线构造，如角平分线） | 沿用第一条父直线的规则（先选两点所在直线） |
| 射线 | 同直线，无负值 |
| 圆 | 0~2π（起点=圆心右移半径处） |
| 圆弧 | 0~1，起点=圆弧起点 |
| 封闭连续折线（多边形） | 0~1，起点=多边形起点 |
| 复合路径 | 总长对应 0~1，各段按长度与顺序分摊 |
| 不在路径上的点 | 按正投影（法线与路径交点）取值；Shift+测量 |

- 点值范围可改：起/终值可为固定值或表达式；起=终则不可拖动；起>终允许（自定义起终点）。
- **点值双向联动**：给点值参数赋值=移动点；用变量驱动点值=做动画/多点联动。
- 半自由点属性"点值"与"拖动"默认同参；改为不同参数时，拖动点不跟光标，但拖动参数照变。
- **教学意义**：形（点）与数（值）一一对应，是数形结合思想的直接载体——做"点在数轴上表示数"、"函数动点"类课件首选。

## 测量与计算（速查见 cheatsheet.md）

- 测量结果全部基于**当前坐标系**。
- 测量对照：2 点→距离；3 点→角与比例；点+线段→点值/投影点值；2 线段→长度比；路径→长度。

## 关键快捷键（§11）

- 选择：Esc 回选择态；Ctrl+A 全选（元素+Ctrl+A 全选同类）；Alt+↑/↓ 父/子元素；轮选=重叠处反复单击。
- 编辑：Del 删除；Ctrl+Z/R 撤销重做；Ctrl+C/V 复制粘贴；Ctrl+E 编辑定义；Ctrl+P 属性；Ctrl+H 隐藏（Ctrl+Shift+H 全显）；Ctrl+K 显标签。
- 构造：Ctrl+Shift+I 交点；Ctrl+M 中点；Ctrl+L 线段；Alt+= 计算；Ctrl+Shift+P 新建参数；空格=重复上次构造/变换。
- 对齐：Shift+Enter 纵向对齐；Ctrl+Enter 横向对齐；Ctrl+方向键 微调。
- 预览：P 预览；! 强制更新；+/- 快速增减选中变量值。
