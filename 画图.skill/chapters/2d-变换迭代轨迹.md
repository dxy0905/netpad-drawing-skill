# 2D 变换 · 轨迹 · 迭代

> 手册来源：2D §4.7、§4.3.8；3D 篇另有投影/切割见 3d-变换函数.md

## 变换工具组（§4.7）

先选源对象（可多选），再定变换基准；已有"标记"时默认用标记。

| 变换 | 基准对象 | 要点 |
|---|---|---|
| 平移 | 向量 | 三种定向量：标记向量/最后选中的线段/两点；对话框可切"直角坐标"（水平+垂直距离）或"极坐标"（距离+角度）；比例值可缩放向量长 |
| 轴对称 | 直线 | 标记轴默认；末选是线则直接用；否则弹窗拾取 |
| 中心对称 | 点 | 标记中心默认；末选是点则直接用 |
| 旋转 | 点 | 对话框设角度，角度可为变量/表达式 |
| 缩放 | 点 | 对话框设比例（可为变量/表达式） |
| 反演 | 圆 | 以圆为反演圆 |
| 仿射 | 规则 | 按仿射规则（原点+两基向量）变换 |

- **标记**（快捷工具栏）：标记向量/轴/中心后，后续变换默认套用，大幅提速。
- 空格键：对选中元素**重复上一次操作**（含变换参数）。

## 轨迹（§4.3.8）

- 用法：先选**含驱动变量的驱动元素**（一个或多个），最后选**轨迹目标元素**，构造轨迹。
- 或：直接选一个"含驱动变量的目标元素"（如线型上的点、坐标点）。
- 两种模式：由驱动元素驱动；由目标元素的拖动驱动。
- 轨迹=批量构造的引擎：曲线族、包络线、面积扫描都靠它，不要手工复制对象。

## 迭代（§4.7.8）

- 原理：f(原象)=映象，再 f(映象)=新映象，重复 N 次。
- 用法：选迭代原象 → 迭代对话框指定映象 → 设深度 N。
- 原象必须：自由点/约束点/参数值/度量值/计算值；映象：各类点/度量值/计算值。
- 选项：随机（约束值随机或按设定）、含点（是否含点对象）、终像（只画最后一次图象）。
- 典型应用：雪花曲线、螺旋、正方形套嵌、n 等分点。

## 动作|显隐（§4.9.3，交互编排）

- 动作按钮可串多步动作，蓝=已执行、绿=下一步、白=未执行；可拖图标排序。
- 8 种动作：显示 / 隐藏 / 开始播放 / 停止播放 / 设置变量 / 点的移动 / 清除跟踪像 /（3D 另有切换视点）。
- 典型教学脚本：显示图 1 → 点移动 → 设置变量 → 停止动画 → 清除跟踪像。
