# 智能画笔 · 五心 · 经典构造（官方作图方法精髓）

> 来源：项目《网络画板作图方法精髓.md》+《网络画板官方学习资源清单.md》（2026-10-17 张训整理，helpbook 几何定理合集/系列视频课程）
> 核心信条：「你画的是条件，软件算的是结果」「约束由构造保证，绝不数值凑」。

## 一、智能画笔 12 种提示词 → 官方构造

智能感应作图（智能笔手绘）自动识别约束，提示词与官方元素一一对应；无智能笔时按右列构造手动做，结果等价：

| 提示词 | 官方元素 / 等价构造 |
|---|---|
| 垂直 / 垂足 | FootPoint 垂足（点+线） |
| 平行 | OnPLinePoint 线上点（平行线工具） |
| 相等 | OnEqualSegmentPoint 等分点/等距点 |
| 平行且相等 | 平移构造平行四边形 |
| 中点 | MidPoint |
| 垂直相等 | 中垂线 + 定长圆 |
| 过点交于线 | ParallelIntersection |
| 切点 / 切线 / 相切 | TangentLine；等价泰勒斯构造：以 OP 为直径作圆 ∩ 原圆 = 切点 |
| 平行相交 / 垂直相交 | 线线交点 |
| 角平分线 | 线线关系→角平分线 |
| 定长 | 圆：圆心+半径（半径可变量） |
| 定比 | 变换→缩放（比值恒成立） |

红线：**约束用构造保证，禁止直接填坐标硬凑**（否则一拖动关系就崩）。

## 二、三角形五心（代数公式精确构造）

| 心 | 定义 | 代数公式 |
|---|---|---|
| 重心 G | 三条中线交点 | G = (A+B+C)/3 |
| 内心 I | 三条角平分线交点 | I = (aA+bB+cC)/(a+b+c)，a=|BC|, b=|CA|, c=|AB| |
| 外心 O | 三边中垂线交点 | 解 2×2 线性方程组（到三顶点等距） |
| 垂心 H | 三条高交点 | H = A+B+C − 2O（欧拉关系） |
| 旁心 | 角平分线交点（3 个） | 到一边及另两边延长线等距 |

- **欧拉线**：外心—重心—垂心共线，且 HG = 2·GO。
- **欧拉公式**：d² = R² − 2Rr（d=外心到内心，R 外接圆半径，r 内切圆半径）。

## 三、核心定理作图方法（几何定理合集）

- 中位线定理：取两边中点连线 → 平行于第三边且等于其一半（配测量对照）。
- 勾股定理：直角三角形（直角靠**垂线**构造）+ 三边平方测量。
- 圆周角定理：同弧所对圆周角 = 圆心角一半；推论：直径所对圆周角为直角。
- 垂径定理：弦 + 圆心到弦的垂足 → 平分弦。
- 切线长定理：圆外一点引两切线长相等（切线工具）。
- 托勒密定理：圆内接凸四边形，两组对边乘积和 = 对角线乘积。

## 四、经典构造（照做即用）

- **定长底边**：圆心在定点、半径=定长的圆 ∩ 水平轴 → 交点即底边另一端点。
- **切线（泰勒斯定理）**：以 OP 为直径作圆，与圆 O 的两交点即切点（无切线工具时的标准做法）。
- **动态圆**：两点圆 2PointsCircle(O,A)，A 放水平轴上，半径随 A 伸缩。
- **任意角**：圆上任取点 B + 射线 OB，∠AOB 即得。
- **特殊角移动按钮**：Rotate 到目标角（隐藏旋转目标）+ 动作按钮设参数（一键切 30°/45°/60°）。
- **整比关系**（3:4:5 直角三角形）：变换→缩放派生，拖动后比值恒成立。

## 五、教师构图默认规范（自动出图遵守）

1. **定点 + 水平底边**：第一个点定点、第二个点在水平轴上 → 底边水平、只横向伸缩，图形稳固、课堂可缩放。
2. **定长底边**：用「圆 ∩ 水平轴」取交点；底边不定长直接轴上取点。
3. **成品三原则**：隐藏辅助对象（构造圆/辅助点/垂线）→ 精简标签（只留必要点标签）→ 动画手动播放（打开即静止，交互由教师触发）。

## 六、函数图象作图要点

- 函数曲线统一挂**自定义坐标系 UCSAxis**（原点→轴端点→控制点→轴线→坐标系），不挂全局轴。
- 变量尺 VariableRuler 创建参数（名称/范围/步长）；表达式用 `^` 乘方，如 `a*x^2+b*x+c`。
- 五点法/描点法讲的是「为什么平滑连接」——拖点看连续性。
- 单位圆三线同屏：sin 红（纵向投影）、cos 绿（横向投影）、tan 蓝（正切线），转动即见四象限符号。
