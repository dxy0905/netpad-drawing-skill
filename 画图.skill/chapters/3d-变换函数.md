# 3D 变换 · 切割 · 迭代 · 函数曲面

> 手册来源：3D §4.8-4.11

## 变换工具组（§4.8）

- **平移**：源对象+向量（线段/两点），同 2D。
- **对称**：基准可为点（中心对称）/线（轴对称）/平面（面对称）；标记中心/轴/平面后直接变换。**3D 独有：平面对称**。
- **旋转**：源对象+旋转轴，默认角度 π/2 可改；方向按右手规则（右手拇指=轴矢量，食指=旋转方向）；属性可切逆/顺时针、角度可关联变量。
- **缩放**：源对象+缩放中心，默认 0.5。
- **投影**：投到线或平面；默认正投影；投到平面可设"光线"（点=点光源；线/面=平行光源方向）；"投影率"0~1（1=源对象本身）。
- **切割**：多面体/圆柱圆台/球/曲面 + 多个平面 → 自动生成**切割动画按钮**；被切体与切割面必须实际相交才见动画；属性：并行（各部分同步运动）、变换表达式、平移距离。
- **迭代**：同 2D 原理；原象=自由点/约束点/参数/度量/计算值；属性：随机、含点、终像、着色（4 种）。

## 函数图象（§4.9）

### 函数曲线（三种表达 × 两类坐标系）

| 坐标系 | 一般式 | 参数式 | 隐函数 |
|---|---|---|---|
| 直角 | y=f(x)，x 自变量 | x,y,z=f(t)，**t 自变量** | f(x,y)=0 |
| 球面 | r=f(t) | r,m,n=f(t) | f(r,t)=0 |

### 函数曲面（三种表达 × 三类坐标系）

| 坐标系 | 一般式 | 参数式（u,v 自变量） |
|---|---|---|
| 直角 | z=F(x,y) | x,y,z=F(u,v) |
| 球面 | r=F(m,n) | r,m,n=F(u,v) |
| 柱面 | z=F(r,m) | r,m,z=F(u,v) |

- 运算符 5 个：+ - * / ^；函数编辑器面板可选函数与 π、e。
- 属性：离散（只显示取样点）、闭合、阈值；变量范围与采样数可设。

## 变量 · 动画 · 动作（§4.10）

- 变量/动画/图片/音频/自定义函数：与 2D 相同。
- 动作类型比 2D 多"**切换视点**"：当前/左/主/俯四视点，可设切换动画过程。
- 测量（§4.10.6）要点：点→直角坐标/x/y/z；直线→长度/方程/向量分量；圆→半径/面积/周长/方程/法向量；球/正多面体/锥台→体积/面积/半径；长方体→体积/面积；凸包不可测；两线→距离/角度/线段比；点+线型→点值。

## 向量（§4.11）

- 与 2D 相同（构造/加减/数乘/点积），**叉积在 3D 是向量**（法向量，右手定则，起点=第一向量起点）。
- 右键可测向量直角坐标/x/y/z 分量、模长、夹角（点积法，[0,π)）。
