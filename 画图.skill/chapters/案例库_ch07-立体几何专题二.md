## 重点案例：迭代构建球面

1. 引入参数 α，计算 m = α+1
2. 选中参数 α → 选取**迭代工具** → 建立 α→m 的迭代
3. 迭代深度设置为 5 → 十二个五边形球面构建完成
4. 选项：是否显示点 / 只显示最终迭代（性能与显示控制）

## 重点案例：第12篇 投影变换化足球

1. **题目**：用网络画板 3D 制作足球（截头二十面体在其外接球上的投影）
2. **构造球体**：球体工具 → 半径 2.6（基础外观设定/高级设定可调）
3. **截头二十面体**：足球骨架 = 截角正二十面体（12 个五边形 + 20 个六边形）
4. **投影**：把截头二十面体各顶点/棱**投影到外接球**上 → 球面足球图案
5. **旋转投影**：旋转观察足球，投影随视角变化
6. **扫码快阅**：作品 ID 516397

## 完整球体构造流程（通用）

1. **进入网络画板首页** → 开始作图（3D 模式）
2. **构造球体**：球体工具（半径参数，如 2.6）
3. **参数设置**：球半径/分段等参数
4. **旋转投影**：设定旋转轴/角度生成投影
5. **构造投影**：向目标面投影
6. **旋转投影**：动态旋转观察

## 教学要点

- 足球案例是 3D 综合应用巅峰：**体构造 + 迭代 + 投影 + 颜色**四合一
- 迭代深度控制是 3D 流畅度关键：深度 5 可交互流畅，更大深度用于最终渲染
- "只显示最终迭代"选项解决复杂迭代的显示性能问题
- 投影变换把"多面体→球面"的映射可视化，是理解球面几何/地图投影的好素材
