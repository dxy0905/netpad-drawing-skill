# 术语表（画图.skill）

| 术语 | 含义 |
|---|---|
| 自由点 | 可任意拖动的点，动态几何的"自变量" |
| 半自由点 | 只能沿父对象（线/圆/路径…）移动的点，带"点值"参数 |
| 点值 | 半自由点在路径上位置的数值刻画（见 2d-点值测量.md），数形结合的枢纽 |
| 父/子对象 | 构造依赖关系；拖动父对象，子对象实时重算 |
| 路径 | 多元素连接成的连续通路，其上可放半自由点（点值按总长分摊） |
| 复合路径 | 由多种线型元素组成的路径 |
| 轨迹 | 驱动元素（含变量）驱动目标元素扫出的曲线；批量构造引擎 |
| 迭代 | f(原象)=映象 重复 N 次的自动递归构图 |
| 直纹面 | 两条线型元素之间拉出的曲面（2D/3D 均有） |
| 相贯线 | 两个面状对象表面相交的交线（3D） |
| 点法圆/点法弧 | 由圆心+法线确定的 3D 圆/弧（3D 圆必须带法向） |
| 右手规则 | 三点确定平面/圆/弧的法向、旋转方向、向量叉积的方向规则 |
| 标记（中心/轴/向量/平面） | 预设变换基准，之后变换默认套用 |
| 反演/仿射 | 2D 变换：以圆反演；按原点+基向量的仿射规则 |
| 投影/切割 | 3D 变换：投到线/面（可设光源）；用面切实体并生成动画 |
| 锥度 | 台体上/下底比：0=锥，1=柱 |
| 缺口 | 球沿纬度挖掉的球扇大小 |
| 痕长 | 3D 跟踪痕迹保留的个数 |
| 线框/炫彩/遮挡 | 3D 显示模式：只显骨架/七彩渐变/被挡处虚线 |
| 纹理 | 平面/曲面/球体贴图（bmp/jpg/gif/png，左下角像素=通透色） |
| 视点 | 3D 视角：当前/左/主/俯，可作动作切换 |
| 滑杆 | 变量在画布上的可视化控件（可播放/拖动/输入） |
| 动作按钮 | 8 种动作编排的脚本按钮（显隐/播放/设变量/点移动/清迹/视点） |
| 隐函数 | f(x,y)=0 类图象（2D 曲线；3D 曲线/曲面） |
| 准线/渐近线 | 圆锥曲线的构造与属性元素 |
| 当前坐标系 | 测量/坐标点依据的坐标系（2D 可切自定义系；3D 固定右手系） |
| 智能画笔 | 手绘自动感应约束的作图方式；12 种提示词对应垂足/线上点/等分点/中点/切线等官方元素 |
| 指令作图 | 用一句话（提示词三要素）让 AI 生成动态图形；产物必须过"一拖一对"人工验收 |
| 一拖一对 | 红线验收动作：拖参数/点，逐项对照数学事实核验 AI 出图 |
| 结果形式 | 计算/测量结果的显示形态：数值（可设小数位）↔ 代数式（根式/分式），属性→设定中切换 |
| 泰勒斯切线 | 无切线工具时：以 OP 为直径作圆 ∩ 原圆 = 切点 |
| UCSAxis | 函数曲线专用自定义坐标系（原点→轴端点→控制点→轴线→坐标系） |
| VariableRuler | 变量尺：创建参数（名称/范围/步长）的可视化控件 |
