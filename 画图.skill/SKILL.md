# 画图 — 网络画板 2D/3D 作图技能（方法 + 案例库）

## 第一部分：核心心智模型（动手前必读）

1. **你画的是条件，软件算的是结果；约束由构造保证，绝不数值凑**。等腰靠中垂线、直角靠垂线、定长靠圆、比值靠缩放、角靠旋转——禁止直接填坐标硬凑（一拖就崩）。所有对象按构造顺序形成父→子依赖图：拖动父对象，子对象实时重算。设计课件前先想清"谁驱动谁"：自由点→半自由点→派生对象（交点/中点/轨迹）。操作一律"先点工具、后选对象"。
2. **数形结合三件套**。① 点值：把"形"上的位置变成数（路径上 0~1，或弧长等），半自由点都带一个点值参数；② 变量/滑杆：把"数"变回"形"（坐标点、半径、角度都可用变量表达式）；③ 动画：本质是**驱动变量**在起止值间按步数推进（步数×间隔=一次动画时长）。
3. **选择顺序即语义**。两点圆、三点弧、圆锥曲线、向量的起终点、3D 法向：框选按生成顺序、点选按选择顺序，顺序不同图形不同。
4. **右手规则（3D 专用）**。三点平面/圆/弧的法向、旋转方向、向量叉积、球的轴向都由右手规则或点的选取顺序确定。
5. **三个自动化杠杆**：轨迹（驱动元素扫出目标元素的象）、迭代（重复构图规则 N 次）、动作按钮（8 种动作的编排脚本，3D 另加视点切换）。
6. **属性表单四层**：基础（标签/显示/锁定/可选/跟踪）→ 外观（颜色/线宽/填充）→ 设定（构造参数：半径/类型/线面角/锥度…）→ 高级（条件/动态参数）。
7. **坐标系即尺度**。所有测量与坐标点都在"当前坐标系"下进行；2D 可建自定义坐标系，3D 只有单一右手系场景，原点可拖动。
8. **一拖一对红线（AI 出图必做）**。凡 AI 指令作图生成的图形，交付前必须拖动参数/点，对照数学事实核验（拖 a 从 2 到 -2 开口是否翻转？数值是否与实际一致？）。你是验收人，不是转发人；判定反相关的组件立即停用。

## 作图七步法

1. 定父子结构：列出要动哪些点/数，谁派生谁。
2. 建坐标系与参数：显示/自定义坐标系；需要控制的量先建变量滑杆。
3. 布自由点/半自由点：半自由点用"元素上的点"，给出点值参数。
4. 构造派生对象：中点/交点/垂线/平行线/圆/圆锥曲线/函数图象。
5. 批量生成：平移/旋转/缩放/反演/仿射变换，轨迹，迭代。
6. 加交互：动画按钮、动作按钮（显隐/移动/设置变量）、图片/音频。
7. 美化与验证：属性表单调外观；测量验证关系（当前坐标系下）。

## 常用配方（照做即用）

- **动态三角形（三边可拖）**：三点 + 线段×3 → 属性标签命名 A/B/C → 加中线/高线（中点、垂线工具）→ 测角（选 3 点测量）→ 动画可选。
- **函数图象 + 动点**：变量滑杆 t → 坐标点 (t, f(t))（直角坐标点输表达式）→ y=f(x) 曲线 → 给点开启跟踪 → 动画驱动 t。
- **圆锥曲线按定义演示**：两焦点 + 线上半自由点 → 第一定义圆锥曲线；属性"设定"里切椭圆/双曲线/抛物线（e 值控制见第二定义）。
- **3D 旋转体/切割动画**：旋转面工具（母曲线+旋转轴）或圆台/球；切割工具选"多面体+平面"自动生成切割动画按钮。
- **迭代图形（雪花/螺线）**：定义原象→按规则构造映象→迭代工具填深度 N→着色可选。
- **半圆动点平行四边形（9 步标准做法，2026-10-18 邱董亲授）**：见 chapters/2d-参数化构造案例.md —— 缩放/平移/中点/射线交点全部派生构造，只留 B、D 可拖，图形恒成立。
- **指令作图（AI 生成）**：提示词三要素＝画什么＋哪些可变＋怎么看得清；生成后必做"一拖一对"；不满意改提示词重来。验收三档 12 项见 chapters/指令作图与人工验收.md。
- **三角形五心 / 欧拉线 / 经典构造**：代数公式精确构造（G=(A+B+C)/3、内心加权、H=A+B+C−2O）；定长底边＝圆∩水平轴、切线＝泰勒斯构造，见 chapters/智能画笔与五心.md。
- **拿来即用的教材成品**：按上面「关键编号速查」在官网搜课件编号，直接打开/复用官方做好的现成课件，再做一拖一对核验。

## 反模式（别这么干）

- 不用父→子结构直接堆对象：改不动、动不了。
- 忽略选择顺序：圆/弧/向量/圆锥曲线方向全错。
- 需要几十个重复对象时手工复制：用轨迹/迭代。
- 动画不平滑：步数太小；动画太快：间隔太小（步数×间隔=时长）。
- 测量数值不对：先检查当前坐标系（2D）。
- 3D 里"看起来相交"不代表相交：相贯线必须用相贯线工具构造。
- 误用普通圆代替 3D 点法圆：3D 圆必须带法向（点法圆/三点圆）。
- 直接改标签想取消斜体：标签名前加 `\rm `；公式直接写 LaTeX（不需 $$）。
- AI 出的图不拖不验就交付：一拖一对是红线，判定反相关（对错颠倒）必须停用。
- 用数值硬凑图形：等腰/直角/定长/定比必须用构造（中垂线/垂线/圆/缩放）。
- 函数曲线挂全局轴、不开自定义坐标系；讲解稿与图形数值不一致就生成语音（先拖后写、写完再拖）。
- 直接用官网课件不核验就交付：即使是官方成品也要过一拖一对，确认符合本课数学事实。
